# Security & Responsible Disclosure Policy

## 🛡️ Reporting Vulnerabilities

If you discover a security vulnerability, mathematical exploit, or biophysical anomaly within the WerrSoma software stack, please report it responsibly:

* **Contact:** Volkan Dağlı
* **Email:** `ask@answerr.me`
* **Response Window:** We aim to acknowledge receipt within 24 hours and provide an assessment within 72 hours.

Please do not open public GitHub issues for security vulnerabilities before they are coordinated and resolved.
